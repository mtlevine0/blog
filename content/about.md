I'm Matt Levine, and I go by the handle mtlevine0. I have a background in electrical engineering and have spent more than 10 years as a software engineer.

I got my start in internships, first writing embedded firmware for motion control systems that drive machine tools, then building data analysis tools for academic researchers in public health. Since then I've worked in enterprise software development, where I've designed and built systems ranging from in-vehicle infotainment applications to platforms that let test engineers build and run automated tests at scale. Today I build tools and platforms that help engineers put the latest AI coding agents to work, at the cutting edge of agentic software development.

Outside of work, my interests range from DIY home projects and auto repair to hardware and firmware design for embedded systems.

This site is a journal of the projects I work on in my free time. Mostly it's a place for me to look back on my work; if anyone else finds it useful, that's a bonus. I usually have a few projects going at once, and I break each one into milestones that show up here as "Part 1," "Part 2," and so on.
